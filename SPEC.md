# Workout Logger

Acceptance criteria

1. The app opens on Workout History. If there are no entries, it says “No workouts before.”
2. Tapping Add Exercise opens the Log Exercise screen. The form asks for the exercise name, weight in pounds, and number of sets.
3. Weight can be zero for bodyweight exercises. If any field is blank or the number of sets is zero, tapping Save does not create an entry.
4. Saving a valid exercise records today's date automatically and returns to Workout History. The new entry appears at the top and shows the date, exercise name, weight, and number of sets.
5. After saving an exercise, fully closing Expo Go, and reopening the project, the saved exercise still appears in Workout History.
